BUSMATE - HOW TO RUN (3 steps)

1. Install Python from python.org (tick "Add Python to PATH").
2. Unzip this folder.
3. Double-click  run.bat   (Mac/Linux: run.sh)

Your browser opens the website automatically (http://127.0.0.1:5050).

PASSENGERS : no account needed. They book with a mobile number
             and find tickets later under "My Tickets".
ADMIN      : click "Admin" in the footer (or go to /admin/login)
             admin@busmate.com / admin123   (change it in the Admin dashboard)
To stop    : close the black window.
